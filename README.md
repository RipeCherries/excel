## 📊 Краткие сведения

Данный проект представляет собой клон приложения для работы с электронными таблицами, реализованный на самописном
JavaScript фреймворке. Основные особенности:

- **Легковесный фреймворк:** реализован с нуля, включая управление компонентами и их состоянием;
- **State-менеджер:** собственная архитектура для управления состоянием приложения;
- **Динамическое обновление интерфейса:** изменения данных моментально отображаются в пользовательском интерфейсе;
- **Поддержка формул:** возможность использования базовых математических операций прямо в ячейках;
- **Локальное хранилище:** данные сохраняются в LocalStorage, что позволяет продолжать работу после перезагрузки
  страницы.

Проект создан в образовательных целях, демонстрируя основные принципы работы современных SPA (Single Page Application).

## 📊 Установка

Для локального запуска проекта выполните следующие шаги:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/RipeCherries/excel.git
   ```
2. **Перейдите в директорию проекта:**
   ```bash
   cd excel
   ```
3. **Установите зависимости:**
   ```bash
   npm install
   ```
4. **Запустите проект:**
   ```bash
   npm start
   ```

После этого проект будет доступен по адресу `http://localhost:3000`.

## 📊 Использование

После запуска вы можете использовать приложение аналогично `Google Sheets`:

* **Создание и редактирование таблиц:** Добавляйте и редактируйте данные в ячейках;
* **Форматирование:** Применяйте различные стили к ячейкам;
* **Формулы:** Используйте базовые формулы для вычислений.
